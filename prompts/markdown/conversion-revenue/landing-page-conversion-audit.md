# Landing Page Conversion Audit

## Overview

Audits one URL for conversion friction, assuming the traffic to it is already healthy.

## The Prompt

```text
Audit this one landing page for conversion friction, assuming the traffic to it is already healthy:

Page URL: [URL]
Page Content: [paste the page's main copy, or describe it]
Primary Conversion Goal: [what action should the visitor take]
GA4 Data For This Page: [sessions, engagement rate, conversion rate]

Audit the page against these friction points:

1. CLARITY — can a first-time visitor tell what to do within 5 seconds
2. CTA — is there one clear call-to-action, or several competing ones
3. TRUST — is there anything (pricing, proof, specificity) missing that a skeptical visitor would need before acting
4. FORM/PATH FRICTION — if there's a form or checkout step, what's asked that doesn't need to be
5. MOBILE — anything about the layout or copy that likely breaks on a phone

For each issue found, give the specific line or element and the fix, not just the category.

Finish with the single change most likely to move the conversion rate, and why that one first.

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Confirm the page is already getting healthy traffic before auditing — this prompt fixes conversion, not visibility
2. Paste the page's actual copy or describe its layout and content
3. State the one action you want the visitor to take
4. Add whatever GA4 data you have for the page

## Tips

- Run the Traffic-to-Sales Leak Diagnostic first if you're not sure the leak is actually on this page
- One clear CTA beats three good ones competing for attention
- Re-test after any change — a fix based on assumption is still a guess until the data confirms it
