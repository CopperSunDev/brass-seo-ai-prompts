# Commercial Keyword Gap Finder

## Overview

Finds high-commercial-intent keywords a site has topical coverage for but no dedicated page targeting them.

## The Prompt

```text
Find high-commercial-intent keywords my site has topical coverage for but no dedicated page targeting them:

Site: [site URL]
Existing Content Topics: [list your main content topics/categories]
GSC Query Data: [paste queries the site already gets impressions for]
What The Site Sells: [product/service description]

Identify keywords that meet ALL of these:

1. Show clear commercial or transactional intent (comparison, pricing, "best," "for [use case]," near-me, etc.)
2. The site already ranks for or gets impressions on a related informational query
3. There's no existing page whose primary purpose is to capture that specific commercial query

For each gap found, report:
- The keyword and its intent signal
- The existing informational content it's adjacent to
- A suggested page type and working title
- Priority (based on how directly it connects to what the site sells)

Finish with the top 3 gaps to build first.

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. List your main content topics or categories in a few words each
2. Export GSC queries the site already gets impressions for
3. Add a short description of what the site actually sells
4. Paste in

## Tips

- Pair with the Keyword Intent Tier Classifier to confirm the tier before building a page
- A gap between informational coverage and commercial capture is often the fastest page to write — you already have the research
- Recheck after every major content push since informational coverage keeps expanding
