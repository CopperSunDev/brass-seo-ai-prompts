# GA4 Conversion Event Setup Checklist

## Overview

A step-by-step key-event setup for a non-technical owner, so SEO conversions get tracked correctly in GA4.

## The Prompt

```text
Walk me through setting up SEO conversion tracking in GA4 for a non-technical site owner:

Site: [site URL, platform e.g. WordPress/Shopify/custom]
What Counts As A Conversion: [e.g., trial signup, contact form submit, purchase]
Current GA4 Setup: [describe what's configured today, or say "nothing configured yet"]
Analytics Access Level: [admin / editor / view only]

Produce a step-by-step checklist covering:

1. KEY EVENT SETUP — which GA4 event to mark as a key event (formerly "conversion"), and how to create it if it doesn't exist
2. ORGANIC SEGMENT — how to filter the key event report to Organic Search traffic only
3. LANDING PAGE ATTRIBUTION — how to see which landing page drove each conversion, not just which page it happened on
4. VERIFICATION — how to confirm the event is actually firing (test conversion, DebugView, or Realtime report)
5. COMMON MISCONFIGURATIONS — the 3 most common reasons a key event silently stops firing or double-counts

Format the output as a numbered checklist I can follow in GA4's interface without needing a developer.

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Note your site's platform and what a "conversion" means for your business
2. Describe your current GA4 setup honestly, even if it's "nothing yet"
3. Confirm your access level so the steps match what you can actually click
4. Paste in and follow the checklist in order

## Tips

- Verify the event fires with a real test action before trusting any report built on it
- Re-check quarterly — platform updates (Shopify, WordPress plugins) can silently break event tracking
- Both GSC and GA4 are required to see the full picture — GSC shows the search, GA4 shows what happened after the click
