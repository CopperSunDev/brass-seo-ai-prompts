# Press Release Writer

Write a PRLog.org-ready press release with proper news-style format and UTM tracking. Use this in ChatGPT or Claude.ai after identifying your newsworthy angle.

```text
Write a press release for PRLog.org Premium distribution.

Company: [company name]
Location: [city, state]
Announcement: [your newsworthy angle]
Key facts: [2–3 specific facts, numbers, or data points]
Links to include (up to 5):
  1. Homepage — [URL]
  2. Main landing page — [URL]
  3–5. [Additional relevant pages]
Target keyword: [primary keyword to place in first paragraph]

Write a 400–500 word press release:
- Open with: [City, Date] — [Company] [verb] [what happened]
- Professional, factual, third-person, news-style
- No promotional language ("amazing", "revolutionary", "best")
- Include a quote attributed to [Name], [Title]
- End with an "About [Company]" boilerplate paragraph
- Contact block with name, email, website

Add UTM tracking to all links:
?utm_source=prlog&utm_medium=press-release&utm_campaign=[campaign-name]

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Run the Press Release Angle Finder prompt in Brass-SEO first to find your newsworthy angle
2. Fill in all the placeholders with your company details, announcement, and links
3. Run in ChatGPT or Claude.ai to generate the draft
4. Review for accuracy, then submit to PRLog.org via their Premium plan ($49/release)

## Tips

- Never use promotional language — PRLog's editors will reject it
- 400–500 words is the ideal length for syndication
- Always add UTM parameters to track traffic in GA4
- Submit one press release per newsworthy event — don't manufacture news
