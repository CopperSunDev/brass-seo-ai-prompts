# Meta Description Writer

## Overview

Generate SEO-optimized meta descriptions for any page. Get 5 options within the 160-character limit, matched to search intent, with character counts and effectiveness notes.

## The Prompt

```text
Write SEO-optimized meta descriptions for the following page:

Page URL or Title: [paste URL or page title]
Page Content Summary: [paste first 2-3 paragraphs or describe what the page is about]
Target Keyword: [primary keyword you want to rank for]
Page Type: [service page / blog post / product page / landing page / about page]
Business Name: [your business name]
Location (if local): [city/region, or skip if not local]

Generate 5 meta description options that:
- Stay between 150-160 characters (count each one)
- Include the target keyword naturally in the first half
- Match the search intent (what would someone searching this keyword want to see?)
- End with a reason to click (benefit, credential, CTA, or curiosity hook)
- Sound like a human wrote them, not a robot

For each option, provide:
1. The meta description text
2. Exact character count
3. What makes it effective (1 sentence)

Then recommend which option works best for this specific page and why.

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Copy the page URL or title you need a meta description for
2. Paste the first few paragraphs of the page content (or summarize what the page covers)
3. Add your target keyword — check Google Search Console for the keyword driving the most impressions to that page
4. Run in ChatGPT, Claude, or any AI tool
5. Pick the best option and add it to your page's HTML or CMS

## Expected Output

- 5 meta description options within 150-160 characters
- Character count for each option
- Explanation of what makes each effective
- A recommendation for the best option

## Tips

- Include your location for local service pages — it makes a noticeable difference in CTR
- If you have a page with high impressions but 0 clicks, fix that meta description first
- Test the output in a SERP preview tool to see how it looks in Google
- Run this prompt again after major page updates to keep the description current
