# Press Release Angle Finder

Identify the best newsworthy angle for a press release from your site data. Run this in your Brass-SEO chat to surface milestones and data worth announcing.

```text
Help me find the best newsworthy angle for a press release to earn backlinks.

Using my site and traffic data, identify:
1. Milestones worth announcing (traffic growth, content output, time in business)
2. Content I've published that contains original data, surveys, or research
3. Features, services, or products I've launched recently

For each angle:
- What's the headline?
- Is this genuinely newsworthy?
- Which pages should I link to (up to 5 with PRLog Premium)?
- What target keywords should appear naturally in the first paragraph?

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Paste this prompt into your Brass-SEO chat
2. Brass-SEO will analyze your site data to surface milestones and announcement candidates
3. Choose the strongest angle and use the Press Release Writer prompt to draft the release
4. Distribute via PRLog.org Premium ($49/release, up to 5 links)

## Tips

- Milestones don't need to be dramatic — first 100 customers, 1 year in business, new service launch all work
- Original data or research makes the strongest press release angle
- Identify your 5 most valuable pages to link before writing the release
