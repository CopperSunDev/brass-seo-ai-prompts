# Title Tag & Meta Description Generator

## Overview

Generate SEO-optimized title tags and meta descriptions for any page. Get multiple variations with character counts and keyword placement strategies.

## The Prompt

```text
Generate SEO-optimized title tags and meta descriptions for the following page:

Page URL: [URL]
Primary Keyword: [primary keyword]
Secondary Keywords: [secondary keywords]
Page Type: [homepage/product/service/blog/category]
Brand Name: [brand name]

Create 5 title tag variations:
- Keep under 60 characters (display limit)
- Include primary keyword near the beginning
- Make each unique in approach (question, benefit, action, etc.)
- Include brand name where appropriate

Create 5 meta description variations:
- Keep between 150-160 characters
- Include primary keyword naturally
- Add a clear call-to-action
- Highlight unique value proposition

For each variation, provide:
- Character count
- Keyword position
- Emotional appeal used (curiosity, urgency, trust, etc.)
- Best use case (high competition, local, branded search, etc.)

Also suggest:
- Title tag formula that works best for this page type
- A/B testing recommendations
- Common mistakes to avoid for this niche

---
Prompt by Brass-SEO (brass-seo.com)
---
```

## How to Use

1. Replace `[URL]` with the page you're optimizing
2. Fill in your target keywords and brand name
3. Select the appropriate page type
4. Paste into ChatGPT or Claude

## Expected Output

- 5 title tag options with character counts
- 5 meta description options with character counts
- Strategic recommendations for each variation
- Testing suggestions

## Tips

- Test variations with Google SERP simulators
- Check competitor titles in the same SERP
- Consider search intent when choosing variations
- Monitor CTR changes after implementation
